How programs behave
Press and Wait for button set last_result to true or false. Use it in an If block. Call program stores the child's Return value in your chosen variable and also in last_result.
Dry runs simulate false button results and numeric reads of zero; waits are shortened. They never capture Android or send input.
Run uses saved versions of all called programs. Changes made while running apply to the next run. Stop is checked between actions and during waits. Service restarts end the run.
Author an oil Number / OCR crop in the template editor first. Unreadable numbers fail the run.
